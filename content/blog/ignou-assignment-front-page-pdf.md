## **IGNOU Assignment Front Page vs Assignment Cover Page**

The terms IGNOU assignment front page, assignment cover and assignment first page are used interchangeably in searches, but the expected format must be in line with the latest instruction of the IGNOU rather than with the terminology used online.

### **IGNOU Assignment First Page**

The opening page of IGNOU assignments lists the students’ enrollment numbers, program codes, course codes, study centers, and submission information.

### **IGNOU Assignment File Cover**

An **IGNOU assignment file cover** refers to the physical file or folder used to organise the assignment when the study centre requires a particular submission arrangement.

### **IGNOU Assignment Cover**

The IGNOU assignment cover should have the student and course details and should not leave out mandatory data necessary for submission.

## **IGNOU Project Cover Page vs Assignment Front Page**

An **IGNOU project cover page** should not automatically be used in place of an assignment front page because projects and assignments have different identification requirements.

| IGNOU Assignment Front Page | IGNOU Project Cover Page |
| ----- | ----- |
| Used for assignments | Used for projects |
| Identifies course and student | Identifies project title and student |
| Generally attached to assignment | Used with project report |
| Course code is important | Project/research details are important |
| Assignment submission | Project submission |

This distinction is important when searching for an **IGNOU front page PDF**, because assignment templates and project templates serve different purposes.
